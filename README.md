# Advanced Video Filters and Keyframe Animations in Shotcut

## Project Overview
This project demonstrates advanced video editing techniques using Shotcut, including keyframe animation and video filters.

## Tools & Technologies Used
- **Editor:** Shotcut
- **Hosting:** GitHub
- **Video:** Nature and mountain landscape

## Lab Journey & Implementation

### 1. Pre-Production
- Imported the landscape video into Shotcut.
- Added the video to the timeline.

### 2. Applying Advanced Filters
- Applied Size, Position & Rotate.
- Applied Color Grading to improve the visual appearance.

### 3. Keyframe Animation
- Created a starting keyframe at 00:00:02.
- Created an ending keyframe at 00:00:05.
- Adjusted zoom to create a smooth zoom-in effect.
